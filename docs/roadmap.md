# TruePath AI Roadmap

This roadmap describes product sequencing by technical and ethical readiness, not calendar time.

## Foundation

- Next.js App Router application
- TypeScript and ESLint
- TailwindCSS and shadcn/ui design system
- Framer Motion landing page foundation
- Prisma schema prepared for PostgreSQL
- Documentation for vision, product, brand, and ethics

## MVP product layer

- Consent-aware onboarding
- First student reflection journey
- Student dashboard shell
- Guardian-safe summary language
- Basic school administrator shell
- Authentication and role boundaries

## AI readiness layer

- Prompt governance and review process
- AI response safety rules
- Human-readable explanations for suggestions
- Audit trail for generated insights
- Age-aware moderation and escalation paths

## Platform layer

- PostgreSQL production database
- Authentication provider integration
- Organization and school tenancy model
- Privacy controls and data export
- Analytics limited to ethical aggregate insights

## Research and validation

- Student comprehension testing
- Guardian and educator feedback
- Bias and harm review
- Accessibility review
- Internationalization readiness

## Guiding constraint

TruePath AI should scale only the parts of the product that preserve student dignity, agency, and openness.
